## 🚀 Projetos em destaque

### 📊 Industrial Fleet Telemetry BI

🔗 [Acessar repositório](https://github.com/Caibny/industrial-fleet-telemetry-bi)

Pipeline de dados voltado à análise da operação de empilhadeiras industriais. O projeto integra telemetria por API, realiza tratamento e modelagem dos dados e disponibiliza indicadores operacionais em dashboards Power BI.

**Principais indicadores:**

- OEE — Overall Equipment Effectiveness
- TEEP — Total Effective Equipment Performance
- Disponibilidade
- Utilização
- Eficiência operacional da frota

**Tecnologias:** API de Telemetria, ETL, Power BI, DAX e Power Query

---

### 🛒 Smart PDV & Gestão de Estoque

🔗 [Acessar repositório](https://github.com/Caibny/smart-pdv-estoque)

Sistema comercial completo para operação de Frente de Caixa, com controle de estoque, emissão de comandas térmicas e acompanhamento financeiro.

**Principais recursos:**

- Frente de Caixa — PDV
- Controle de inventário
- Comandas térmicas
- Dashboard financeiro e BI
- Gestão de vendas e produtos

**Tecnologias:** Python, FastAPI, SQLite e Chart.js
